# Buzdolabi Lambasi Mahkemesi

Resmi olmayan resmi kurum. Eskisehir 4. Agir Ceza Mahkemesi'nin yan dairesi, aslinda mutfak. Gorevimiz tek ve kutsaldir: **kapak kapaninca lamba soner mi?**

Bu soru felsefe degil, usul hukukudur. Taniklar yalan soyler. Kedi yalan soylemez ama ifade vermez. Sensor 2014'ten beri izinlidir, raporu kayiptir.

## Kurumsal vizyon

Kapak acikken herkes aydinlik sever. Kapak kapaninca herkes filozof olur. Biz ikisinin arasinda durup tutanak tutariz. Tutanak islanir, cunku biri sut dokmustur.

## Kurulum

```bash
git clone https://github.com/Tentivory/buzdolabi-lambasi-mahkemesi.git
cd buzdolabi-lambasi-mahkemesi
python3 mahkeme.py
```

Python 3 yeter. Dis bagimlilik yok. Hakimler ac degil, paket istemez.

## Kullanim

Program sizden uc sey ister:

1. Kapağın son goruldugu hal (acik / kapali / aralik / kedi icinde)
2. Tanik ifadesi (serbest metin, yalan serbest, abarti tesvik edilir)
3. Buzdolabinin markasi (yoksa `markasiz` yazin, markasiz da vatandastir)

Cikti bir karardir. Karar baglayicidir, ta ki siz kapagi tekrar acana kadar. Temyiz yolu: programi tekrar calistirmak.

## Ornek durusma

```text
Kapak durumu: kapali
Ifade: icinden bir tik sesi geldi, bu ya role ya da vicdan
Marka: markasiz
```

Mahkeme, roleyi sanik, vicdani musteki ilan eder. Lamba durumu ihtimal olarak hesaplanir. Ihtimal yuzde olarak verilir, cunku yuzde ciddi durur.
